Telco Customer Churn Analysis
Customer churn analysis for ABC Communications Ltd, completed as part of the AnalystLab Africa Data Analytics Internship (Week 1).
Business Problem
ABC Communications Ltd is losing customers to churn. This project investigates who churns, why, and what actions management can take to improve retention.
Dataset
[Telco Customer Churn Dataset] (https://www.kaggle.com/datasets/blastchar/telco-customer-churn) — 7,043 customer records, 21 features.
Key Findings
- Overall churn rate: 26.5%
- Month-to-month contract customers churn at ~43%, vs ~3% for two-year contracts
- Electronic check payment users churn far more than automatic payment users
- Fiber optic customers churn more than DSL, despite being the premium product
- Tenure is the strongest predictor of retention — the first few months are critical

Tools Used
Python (pandas, matplotlib, seaborn) in Jupyter Notebook
